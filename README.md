# DIY_pulse_oximeter
Hello! I made this project just as a way to make medical equipment with cheaper components(while retaining quality of the measurements)

# Description
The device uses MAX30102 to measure pulse and SpO2, and the microcontroller is Atmega328p(like the one on arduino nano). I am planning to use a 64x32 0.49" OLED screen to display info, and I also integrated a MCP73831 charging circuit for the battery(planning to use 250mAh tiny li-po), and CH340C for quickly writing firmware.
